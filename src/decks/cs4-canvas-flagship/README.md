## What this deck is — and how it differs from `cs4-flagship-v1/`

`cs4-flagship-v1/` is a 10-slide deck with one slide per camera position
(traditional slide-per-route model). It uses CaseHeroDivider, AiBrain, and
the standard SlideGrid layout system.

`cs4-canvas-flagship/` is a **continuous-canvas** deck. It registers as
**ONE slide** in the manifest, but that one slide is an 8000×4500
logical canvas with 10 internal "camera positions" you navigate via
arrow keys (or `#cam-N` hash). All 9 zones (A–I) are always rendered;
the camera (a `motion.div` parent transform) pans/zooms across them.

This means:
- Shared elements (Analyst icon, LLM badge, architecture nodes,
  PharmState bus, audit chain) are **the same DOM nodes** across all
  camera positions — no remount, no recreation. `layoutId` morphs work
  natively because nothing unmounts.
- The finale (camera 10) zooms out to scale 0.3 and shows the entire
  canvas at once — every zone the panel was shown is still there, in
  one continuous space. This is the load-bearing wow.

## Architectural choice

**Option A** of the build plan: single-slide manifest entry with
internal camera state. Trade-off: loses native per-slide progress bar
and PresenterView per-slide notes; gains true continuous-canvas
behavior with smooth `motion.div` camera transforms.

The TracingBeam (right edge, hand-rolled, layoutId-tagged) shows
progress N/10 internally. Camera notes are toggled by `N` key, drawer
at bottom of viewport.

## IP firewall

✅ Show: agent role names, architectural counts, M15 pillar mapping,
  schema-extractor boundary concept, hash-chain mechanism,
  comparison posture vs published systems.

❌ Hide: actual prompts, agent system messages, tool implementation
  code, exact deployment topology, real SHA-256 inputs, dataset names,
  license-restricted patient identifiers.

Every on-canvas hash, schema name, and tool window label is **plausible
sample data** — never traced from a real session.

## How to run

```bash
cd 4-Apps/merck-deck
npm run dev
# open http://localhost:5173/decks/cs4-canvas-flagship
```

Navigation:
- `→` / `←` — next / prev camera position
- `Space` — next camera
- `N` — toggle speaker notes drawer
- `1`–`9` / `0` — jump to camera 1–9 / 10
- URL hash `#cam-5` syncs to camera 5
